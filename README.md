**Random Number Game**

**📖 Description**
> This project is a simple command-line game built using Python where a human player competes against the computer by choosing numbers within a defined range.
> The computer generates a random number, and the winner is determined by comparing both values. If both numbers are equal, the result is a tie; otherwise, the higher number wins.
> This project demonstrates basic Python concepts such as loops, conditionals, user input handling, and random number generation.

**🚀 Features**
1. Human vs Computer gameplay
2. Random number generation for computer
3. Win/Loss/Tie logic
4. Input range validation (1–100)
5. Continuous gameplay with replay option

**🛠️ Tech Used**
Python (no external libraries required)

**📂 How It Works**

1. The user enters a number between 1 and 100
2. The computer generates a random number in the same range
3. Both numbers are compared:
> Same number → Tie
> Higher number → Winner
4. User can choose to play multiple rounds
